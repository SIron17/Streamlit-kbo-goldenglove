# KBO 골든글러브 수상 예측

## 📋 프로젝트 개요
이 프로젝트는 KBO 리그의 역대 데이터(1984~2023)를 기반으로, **2024년 골든글러브 수상자를 예측**하는 머신러닝 모델을 개발하였습니다.  
예측 모델은 각 포지션별로 훈련된 신경망을 사용하며, `Statiz`와 KBO 공식 사이트에서 수집한 데이터를 활용했습니다.

## 🏗 주요 기능
- **포지션별 신경망 모델**: 투수(P)와 타자별 포지션(C, 1B, 2B 등)에 따라 최적화된 모델 설계
- **골든글러브 수상자 예측**: 2024년 후보 데이터를 입력하여 각 포지션별 최적의 수상자를 예측
- **Streamlit 서비스**: 예측 결과를 직관적으로 시각화하여 제공
- **데이터 크롤링**:
  - **정량적 데이터**: `Statiz`를 사용해 선수별 WAR, 타율, OPS 등 주요 성적 수집
  - **골든글러브 수상 데이터**: KBO 공식 사이트에서 역대 수상 기록 수집

## 🧰 사용 기술
- **프로그래밍 언어**: Python
- **머신러닝 프레임워크**: TensorFlow/Keras
- **데이터 전처리**: Pandas, NumPy, Scikit-learn
- **웹 서비스**: Streamlit
- **데이터 수집**: BeautifulSoup

## 📊 데이터
### 데이터 소스
1. `Statiz`: 선수별 정량적 성적 데이터 (1984~2023)
2. `KBO 공식 사이트`: 역대 골든글러브 수상자 데이터 (1984~2023)

### 데이터 구성
- **타자 데이터**: WAR, oWAR, dWAR, OPS, wRC+ 등 19개의 주요 지표
- **투수 데이터**: ERA, WHIP, FIP, rRA9 등 20개의 주요 지표
- **골든글러브 여부**: 각 선수의 수상 여부를 타겟 값으로 설정

## 📐 모델 구조
- **입력**: 타자 및 투수의 정량적 성적 데이터
- **은닉층**:
  - Dense Layer (128, 64 units, ReLU 활성화 함수)
  - Dropout (30% 드롭아웃 비율)
- **출력**: Sigmoid 활성화 함수로 이진 분류 (수상 여부)
- **최적화 및 손실 함수**:
  - Optimizer: Adam
  - Loss: Binary Crossentropy

## 🧪 모델 학습
### 1. **클래스 가중치 적용**
- 불균형 데이터(수상/비수상)의 영향을 줄이기 위해 클래스 가중치를 계산하여 적용

### 2. **Early Stopping 및 Checkpoint**
- 학습 조기 종료(Early Stopping)를 통해 과적합 방지
- 최적의 모델을 저장하기 위한 Checkpoint 설정

### 3. **모델 저장**
- 각 포지션별 학습된 모델을 `.keras` 형식으로 저장

## 🚀 Streamlit 서비스
**Streamlit**을 사용하여 다음 기능 제공:
1. CSV 데이터 업로드로 선수 정보를 입력
2. 각 포지션별 예측 결과를 시각화
3. 선수별 수상 확률과 성적 지표를 그래프로 표시

### 주요 성과
1. **1순위 예측 정확도**  
   모델이 예측한 1순위 중 실제 수상자를 맞춘 비율  
   - 맞춘 포지션: 투수, 1루수, 2루수, 3루수, 외야수(구자욱, 로하스)  
   - **총 10개 포지션 중 6개 맞춤** → **60%**

2. **1순위 + 2순위 정확도**  
   모델이 예측한 1순위와 2순위 중 하나라도 실제 수상자를 포함한 비율  
   - 맞춘 포지션: 투수, 포수, 1루수, 2루수, 3루수, 유격수, 외야수(구자욱, 로하스)  
   - **총 10개 포지션 중 8개 맞춤** → **80%**

3. **정밀도 (Precision)**  
   - **1순위만 포함**:  
     모델이 1순위로 예측한 수상자 중 실제로 맞춘 비율  
     - Precision (1순위) = True Positives / (True Positives + False Positives)  
     - Precision (1순위) = 6 / (6 + 4) = 60%  

   - **1순위 + 2순위 포함**:  
     모델이 1순위와 2순위로 예측한 수상자 중 실제로 맞춘 비율  
     - Precision (1+2순위) = True Positives / (True Positives + False Positives)  
     - Precision (1+2순위) = 8 / (8 + 8) = 50%

4. **재현율 (Recall)**  
   실제 수상자 중 모델이 맞춘 비율  
   - Recall = True Positives / (True Positives + False Negatives)  
   - Recall = 8 / (8 + 4) = 8 / 12 ≈ 66.7%

5. **F1-score**  
   Precision과 Recall의 조화 평균  
   - F1-score = 2 × (Precision × Recall) / (Precision + Recall)  
   - F1-score = 2 × (0.5 × 0.667) / (0.5 + 0.667) ≈ 57.1%

### 개선 방안
1. **팀 성적 요소 반영**  
   박찬호와 최형우는 팀 성적이 골든글러브 수상에 중요한 정량적 요소로 작용한 것으로 보인다.  
   모델 학습 시 팀 순위를 반영하는 것이 좋을 것 같다.

3. **신기록 달성 여부 반영**  
   레이예스는 KBO 단일 시즌 최다 안타 신기록을 달성하여 골든글러브 수상에 중요한 비정량적 요소로 작용한 것으로 보인다.  
   주요 신기록 달성 여부를 데이터에 추가해 모델 학습에 반영하면 더 나은 예측 결과를 얻을 수 있을 것 같다.

5. **비정량적 요소 반영**  
   명성이나 이미지, 인기처럼 숫자로 표현하기 어려운 비정량적 요소가 투표 결과에 영향을 미칠 수 있기 때문에  
   이를 정리해 모델 학습에 포함하면 예측 성능을 더욱 향상시킬 수 있을 것 같다.

### 느낀 점
모델은 주요 포지션에서는 선수 성적에 따라 예측하여 괜찮은 성능을 보였다.  
하지만 신기록 달성 여부, 명성과 인기 같은 비정량적 요소가 일부 반영될 수 있다는 점을 깨달았고,   
비정량적 요소를 반영한 추가 개선이 필요하면 더 나은 성능을 보일 수 있을 것으로 보인다.
